# Theme Brief

## Marketplace
Shopify Theme Store / ThemeForest

## Niche
Fashion / apparel

## Target Merchant
Small to mid-size fashion brands that need a polished storefront without custom development.

## Differentiator
Editorial product discovery with fast mobile shopping and flexible promo storytelling.

## Non-Negotiables
- Mobile-first
- WCAG 2.1 AA
- Theme editor friendly
- No Dawn/Horizon dependency for Shopify Theme Store
- Under 3s perceived load on 4G
- Minimal dependencies
