# Editorial Fashion Theme

Original Shopify Online Store 2.0 theme foundation for a premium fashion storefront.

## Development

Use Shopify CLI to preview and validate the theme:

```powershell
shopify theme dev
shopify theme check
```

## Quality Targets

- Mobile-first responsive layout
- WCAG 2.1 AA baseline patterns
- Merchant-editable sections and settings
- Minimal JavaScript
- Lazy-loaded product imagery
