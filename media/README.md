# Media Replacement Guide

Use this folder for local campaign planning files only. Shopify does not upload arbitrary theme folders to the storefront, so final images should be added through the theme editor image pickers.

Recommended campaign assets:

- Hero: 2400 x 1500 JPG/WebP, strong fashion campaign image
- Editorial split: 1600 x 2000 portrait image
- Collection story cards: 1200 x 1600 portrait images
- Lookbook band: 2400 x 1500 cinematic landscape image
- Product cards: Shopify product media, 3:4 ratio

Avoid using images from other paid themes or demo stores. Use your own shoot, supplier-approved media, or free commercial-use photography.
